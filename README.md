# Planora AI — Improved Frontend Demo

## Open
Extract the ZIP, then double-click `index.html`. No npm, Node.js, React or build step is needed.

## Navigation
Each feature has its own page in the left sidebar:
- Overview
- Event blueprint
- Budget planner
- Timeline
- Vendors
- Guest list
- Theme studio
- AI copilot

On mobile, use the menu button to open navigation.

## Working interactions
- Create an event and generate a local demo blueprint.
- Edit budget categories and rebalance to the total.
- Change guest count and catering style in the What-if lab.
- Add and complete timeline tasks.
- Add vendors and update their statuses.
- Add guests and RSVP details.
- Select a theme direction.
- Ask the contextual demo copilot questions.
- Data persists in browser localStorage.

## AI integration
This is a frontend demo with local domain responses. It does not make live Gemini API calls. To enable live Gemini, connect a secure backend/serverless endpoint and keep API keys on the server. Never add API keys to browser JavaScript.

## Note
Initial figures and vendor entries are illustrative demo data, not quotes or verified vendors.

## 🌟 About Planora AI

Planning a wedding, birthday, or community celebration involves countless decisions, budget constraints, vendor coordination, and deadlines.

**Planora AI changes the way people plan celebrations.**

Planora is an intelligent event-planning assistant designed to turn an event idea into a structured, actionable plan. From personalized themes and smart budget allocation to preparation timelines and vendor checklists, Planora brings the entire planning journey into one workspace.

Our mission is simple:

**Make professional-quality event planning accessible, intelligent, and stress-free for everyone.**

## 🚀 What Makes Planora Different?

Unlike traditional event management platforms, Planora focuses on intelligent decision-making rather than simply managing tasks.

### ✨ Core Features

| Feature | Description |
|---|---|
| 🧠 AI Event Blueprint | Transform event requirements into personalized planning strategies. |
| 💰 Smart Budget Intelligence | Allocate budgets, monitor expenses, and identify savings opportunities. |
| 📊 What-If Event Lab | Explore how guest counts and catering choices affect estimated costs. |
| 📅 Intelligent Timeline | Organize preparation tasks, deadlines, and event-day schedules. |
| 🤝 Vendor Studio | Organize vendor categories, estimated prices, and booking status. |
| 🎨 Celebration Studio | Explore themes, visual directions, and creative concepts. |
| 👥 Guest Experience | Manage guest information, RSVPs, and dietary preferences. |
| ✦ Planora Copilot | Get contextual planning guidance and event recommendations. |

## 💡 Our Innovation

### 1. Event What-If Intelligence
What happens if 100 additional guests attend?

Explore alternative scenarios and understand their estimated financial impact before making decisions.

### 2. Budget Rescue
Identify budget pressure points and discover practical ways to reduce unnecessary spending without compromising the guest experience.

### 3. Celebration Blueprint
Convert a simple event description into an organized starting point containing themes, budget allocations, preparation tasks, and vendor requirements.

### 4. Contingency-First Planning
Think beyond the perfect event. Prepare for unexpected guests, weather disruptions, vendor cancellations, and other potential challenges.
